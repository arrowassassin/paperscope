Capabilities

Built for Production AI Workflows

Every feature designed for real-world agent safety, not demos.

Intercept & Block

Hook into shell execution via LD_PRELOAD. Commands matched against YAML policies before they reach the kernel. Sub-millisecond overhead.

Deterministic Policies

Rules defined in YAML with glob patterns, regex, allow/deny lists, and severity levels. No ML classifiers, no false positives, fully auditable.

Snapshots & Undo

Copy-on-write filesystem snapshots before every intercepted command. One-click rollback to pre-execution state. No data loss, ever.

Tamper-Evident Log

Merkle-tree audit log with SHA-256 chaining. Every interception, policy match, and snapshot cryptographically linked. Detects any post-hoc modification.

Local-First, Zero Telemetry

Runs entirely on your machine. No network calls, no metrics, no phone home. Your code, your policies, your data — never leaves your control.

MCP Server Integration

Expose Kintsugi as an MCP server. Agents can query policy status, request approvals, and retrieve audit logs through standard protocol.
